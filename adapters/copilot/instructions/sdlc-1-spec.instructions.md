# SDLC stage 1 — Spec

Before doing any work in this stage, read `.sdlc/playbook/1-spec.md`
and follow it step by step.

**Produces:** `.sdlc/<slug>/spec.md`

**Gate:** Spec approved, flagged concerns resolved. **Decided by:** Requester (+ tech lead for higher-risk items).
Stop at the gate and ask. Never approve on a human's behalf, and never
start the next stage in the same turn as the request for approval.
